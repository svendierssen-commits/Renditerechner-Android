# Renditerechner Android

Native Android-App zur Berechnung von Sparplänen, Renditen und Zielvermögen. Codebasis neu erstellt, ohne die früheren APK-Startdateien.

## Automatische Prüfung
Der GitHub-Actions-Workflow erstellt eine Android-Debug-APK, führt Rechentests durch und startet die App im Android-15-Emulator. Nach bestandenem Test liegt die APK unter **Actions → aktueller Lauf → Artifacts**.

Hinweis: Debug-APK für persönliche Testzwecke. Es werden keine privaten Signierschlüssel im Repository gespeichert.
